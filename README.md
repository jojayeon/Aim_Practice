🎯 에임 연습 웹 프로젝트 (2D)

----------------------------------------

📝 한 줄 소개

오버워치 위한, 게임 없이도 집중력 저하 없이 에임 실력을 키울 수 있는 2D 웹 에임 연습장

----------------------------------------

📚 프로젝트 목적

오버워치 게임을 좋아하지만, 게임을 실행하면 곧장 플레이에 몰입해 다른 일에 소홀해지는 점을 개선하고자

웹페이지에서 간편하게 에임 연습만 할 수 있는 환경을 만들었습니다.

언제든 브라우저에서 빠르게 에임 연습을 하며, 집중력과 게임 실력을 함께 향상시킬 수 있습니다.
